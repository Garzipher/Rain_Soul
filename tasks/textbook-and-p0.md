# 图文实践教材与 P0 续开发计划

日期：2026-10-09。依据：用户要求教材式阅读、选择 Markdown 源文＋图文阅读，并继续完整 P0；立项 V2.0、PRD 与 Demo 为产品基线。此文件记录开发状态，不缩减产品范围。

## 目标与边界

把默认“项目全流程开发学习”从摘要式记录改成可跟做的项目实践教材。按既有八卷组织，补齐基础概念、环境准备、完整操作、代码解释、预期结果、排错和习题。截图来自实际程序，标注对应界面和阶段；未完成 P0 明确标为计划。

教材原文随包离线提供，Markdown 保留标题、代码、列表、表格、引用、图注。固定 ID 的学习作品默认进入阅读模式，可切到 Markdown 源文、原有个人笔记；用户编辑和删除状态保留。普通小说的固定样式正文契约不变，不把任意 HTML/URL/文件读取权限加入编辑器。

渲染用 react-markdown、GFM 与代码高亮，跳过原生 HTML，远程图片和危险链接禁用。图片来源为课程根目录内白名单 PNG，构建时检查真实路径、格式、尺寸与大小，静态打包，无运行时联网。代码仅作为文本展示。

## 审查重点

1. Markdown 不执行脚本，不加载远程图或任意本地路径；图片缺失构建失败。
2. 阅读源版本与个人笔记明确区分，教材修订不覆盖已有作者内容；同名小说不接管。
3. 阅读/模式/章节切换仍遵循保存门禁；失败保留草稿并阻止离开。
4. 截图均为当前系统实际产物，不写未来能力为已完成。
5. P0 资料是作者级配置，不纳入作品快照；头像解码/超限/写入失败不损坏旧资料。
