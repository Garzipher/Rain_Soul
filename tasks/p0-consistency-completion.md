# P0 数据与交互一致性补全

日期：2026-10-09。以现有立项 V2.0、PRD、技术方案和 Demo 为基线。本轮修复审计发现的实际偏差，不扩大后置功能范围。

## 独立任务与验收

- [ ] 跨作品知识复制：预览原内容、出处及来源，选择当前作品主分类；按名称匹配目标已有标签，可调整选择，未匹配不隐式创建；取消不写入，失败保留选择，防止重复提交和错作品写入。
- [x] 分类与标签维护：未保存草稿阻止其他字典编辑、删除与排序，仍可保存、取消及失败重试；明确说明受阻原因。
- [x] 正文书签：多段正向或反向选择均归属文档顺序首段；单段仍在选区末尾、空选区仍在光标插入；保留原文与稳定 ID，不计字数。
- [x] TXT/DOCX：按正文树的无卷章节在前、分卷章节随后顺序导出；历史冻结稿使用相同规则，引用编号按实际首次出现顺序分配。
- [x] AI：保留目标段落硬换行；已授权章节的大纲祖先、详细计划与相关伏笔进入参考，其他章节正文不混入；范围标签简洁表达章节数，完整清单仍在授权预览，正文容量限制保持有效。
- [x] 教材同步：先解释草稿状态、标识映射、选区位置和数据投影，再给项目源码链路、复现练习与答案。
- [ ] 质量与交付：专项红绿回归、独立 review、完整 verify、生产构建、真实 Electron 与新版目录包检查；原子中文提交到 main。

## 分工和依赖

GSD Core 第一波并行处理知识复制、AI 数据准备；root 处理字典草稿、书签和导出。共享 App 仅知识复制任务修改。第二波统一审查、教材和完整验证；最终重新生成交付包，避免旧 EXE 与已提交源码不一致。

既有旧目录 `release/p0-20261009` 已确认不存在，无需再次删除。作者作品目录不属于产物清理范围。

## 外部验收边界

真实云服务及费用、Microsoft Word 实际打开、干净 Windows 10/11 安装升级卸载需要对应环境；本轮不会以本机测试替代这些结论。
