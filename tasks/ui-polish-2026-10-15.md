## 八项对应结果

| 编号 | 整改内容 | 本轮观察 |
| --- | --- | --- |
| UI-01 双侧栏挤占 | 窄窗主侧栏改为覆盖层；知识分类与会话列表使用覆盖布局；章节可收起 | 展开主侧栏时工作区不重新缩窄；704px 下知识结果区宽约 620px，会话输入区宽约 612px |
| UI-02 写作首屏 | AI 与保存状态常驻；版本、备份、导出收入“更多”；引用工具默认折叠，窄窗章节默认收起 | 最小窗口顶栏约 55px，正文宽约 595px、首行约 y=260px，能够直接阅读样例正文 |
| UI-03 知识卡片密度 | 编辑、删除收入卡片菜单；只展示两行摘要、最多两个标签和标签余数；技术追溯随全文展开 | 常规样例卡片由原约 236px 高压缩到约 155px，摘要和出处成为主要内容 |
| UI-04 出处可读性 | 辅助字号提升至 12px；出处使用 `#596674` | 白底静态颜色对比约 5.9:1；未宣称完成全站 WCAG 审计 |
| UI-05 教材正文优先 | 窄窗本章目录默认折叠，压缩目录和标题前留白 | 704×501 首屏能看到章节标题、开头正文及下一节标题 |
| UI-06 设置导航 | 增加固定分组索引；全局与当前作品分区；删除恢复默认折叠；窄窗横向索引 | 两种窗口下分组入口可见，窄窗全局标题不再被索引遮盖；没有提交设置或验证跳转业务结果 |
| UI-07 滚动归属 | 工作区网格约束行高；根页面禁止滚动，树与详情拥有明确内部滚动容器 | 常规伏笔页面只显示详情滚动条；窄窗上下布局的列表和详情分别滚动，属于两个内容区域 |
| UI-08 证据降噪 | 默认展示证据阶段、章节、第几段和一次摘录；原出处版本、UUID 等收入历史追溯折叠区 | 常规证据画面可直接阅读来源与摘录，数据没有因呈现精简而删除 |

UI-07 的 DOM 记录仍显示根元素存在来自内部布局的溢出高度；根、应用、主区均禁止外层滚动，工作区边界与视口一致。本轮视觉结论为消除了可见的外层双滚动条，不将该数值写成根文档内容高度完全相等。
