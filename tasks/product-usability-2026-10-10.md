# RainSoul 产品可用性：技术团队回归记录

日期：2026-10-10。依据：已批准规格、实际 Electron 测试源码、保留的客户端截图、真实模型及搜索性能记录。本报告汇总七条产品任务的内部技术证据，不冒充真人首次使用测试，也不证明真实作者文学收益。

## 判断与证据规则

离线写作、知识审核、作品隔离、版本恢复和导出具备可执行的回归覆盖。网页安全、本机模型推理、检索质量与客户端界面分别有专项证据；不能把算法实验通过直接写成正式客户端语义检索已经验收。

桌面测试启动真实 Electron，使用隔离作品目录，经真实预加载与主进程 IPC 读写。文件选择框和云响应在需要确定性时使用受控替身，素材为合成文本。部分用例用 IPC 预置资产，再经真实界面操作；这种方式不能证明普通作者无需指导即可首次使用。

当前生产模型受资格门禁保护：研究目录真实 CPU 推理已经运行，正式界面在模型未就绪时使用关键词回退。正式包完整离线语义闭环、真实云文学效果和干净 Windows 安装升级卸载需各自验收。最终全套由主任务串行执行后补入版本、提交及结果；之前专项通过或旧包总数不充作最终门禁。

## 七条产品任务

### 1. 空作品首次写作

步骤：隔离目录启动 → 作品集新建作品 → 编辑章名正文 → 核对实时字数 → 新输入未停顿时正常关闭 → 重启打开原章 → 新建第二章并切回原章。

证据：`tests/desktop/writing.spec.cjs` 的“真实 Electron 创建、离线写作、关闭保存和重启恢复”。不靠隐藏 API 创建作品或正文，检查关闭前最新输入落盘、重启恢复及章节切换。[作品集截图](../learning/项目全流程开发学习/images/shelf.png)、[写作截图](../learning/项目全流程开发学习/images/writing.png)为实际客户端既有画面。

边界：用例是短合成文本，未记录真人撰写 300 字的用时、求助和误操作。预置百万字压力数据不能替代首次写作体验。本任务有真实交互回归覆盖，尚无真人首次使用观察。

### 2. 网页获取并审核入库

步骤：知识库拆书工具 → 选择公开网页并主动获取 → 主进程检查每跳协议/DNS/公网 IP、固定连接及大小/期限 → 无脚本提取 → 冻结网址、标题、时间与哈希 → 作者预览审核后才入库。

证据：`public-web-transport.test.ts`、`web-extraction-commands.test.ts` 等受控网络夹具覆盖传输及取消；`book-extraction-source.test.ts`、`source-assets.test.ts` 覆盖来源事务。`tests/desktop/web-extraction.spec.cjs` 经真实 IPC 验证 45 段粘贴素材的独立双栏滚动、20 段分页、手工修改、保存草稿、重启与更换素材。[双栏截图](../learning/项目全流程开发学习/images/source-double-column.png)、[恢复截图](../learning/项目全流程开发学习/images/source-draft-recovered.png)。原文翻页不改变审核页；重启取消审核勾选与权利确认。

边界：该桌面工作台用例没有访问真实公开网页。攻击夹具通过不等于任意网站提取效果已验收；尚无某个有使用权的真实网页从获取到审核的独立人工任务记录。安全底座与工作台有证据，真实网站效果待验。

### 3. 离线手工入库

步骤：无云配置时选择 TXT → 核对默认零选择 → 取消不写库 → 逐段编辑摘录、出处、分类标签 → 审核确认 → 入库 → 重启核对原文件出处。

证据：`tests/desktop/p1-workflow.spec.cjs` 的“P1本地拆书默认零选择，取消不写库，两段审核真实入库与重启保留出处”，以及 `p0-workflow.spec.cjs` 中知识表单新增流程。[审核截图](../learning/项目全流程开发学习/images/p1-book-extraction.png)、[知识截图](../learning/项目全流程开发学习/images/p1-book-knowledge.png)。`book-extraction-ai.spec.cjs` 还覆盖已完成未采用批次重启恢复：只查询本机完成回答，重启后云发送计数零，恢复建议仍须重新审核。

审查回归：新增本地章序/段号与数据库读取字段不一致，可能阻断同一素材第二批入库。已交由实现者修复，要求含坐标同来源两批真实事务回归。最终通过前，不将第 101 条继续处理标为已验收。

### 4. 不同措辞检索并定位来源

步骤：当前或全局范围输入检索意图 → 关键词/语义/混合 → 核对来源作品和出处 → 跨作品先复制 → 当前作品最多五条写作参考。

证据：`tests/desktop/local-retrieval.spec.cjs` 的真实 IPC 全局关键词及混合回退、出处标注、复制预览与取消。[回退截图](../learning/项目全流程开发学习/images/knowledge-local-fallback.png)、[模型设置截图](../learning/项目全流程开发学习/images/settings-local-model.png)。`retrieval-commands-integration.test.ts` 用实际 WorkRepository 与 StoreService 核对复合身份、层级分类/标签 AND 及旧回执失效。

真实质量见[模型资格记录](retrieval-model-qualification.md)：100 条中文知识、30 个验收查询与独立校准集；15 个改写查询混合 Recall@5 为 13/15（0.8667），关键词为 10/15（0.6667）；五个无相关查询一个误报。标签由开发者预标注，尚无独立真人复核。研究真实模型与正式界面回退是不同证据，不能由实验成绩自动解除生产资格门禁。

### 5. 选用参考、预览取消及确认改稿

步骤：正文右键选句/段 → 知识卡选参考后返回 → 保留选区、候选及生成时原文 → 看完整发送内容与计费提示 → 取消不发送 → 确认生成候选 → 增删对比 → 单独确认写入并保留快照。

证据：`ai-preview.spec.cjs`、`p0-workflow.spec.cjs` 经真实界面核对素材/出处、密钥不回显、取消后正文和快照不变，并将实际右键单句偏移带入预览。[授权截图](../learning/项目全流程开发学习/images/ai-authorization-preview.png)。跨页候选保留、换作品隔离、过期禁用、知识卡选用/移除、五条上限由 `renderer-ai-protection.test.tsx`、`ai-workspace.test.tsx`、`knowledge-workspace.test.tsx` 覆盖；正文变化拒绝旧偏移由 `writing-ai-selection.test.ts` 覆盖。确认改稿/快照原子保护由 `ai-apply.test.ts` 等数据库用例覆盖。

边界：1.3.0真实Electron已验证右键单句→知识卡选用→返回写作→授权预览，目标原句及出处保留；取消不改原稿。删除已选知识会释放额度、过滤无效参考且不跨作品沿用。界面取消和本机事务不替代真实云文学效果、事实保留及费用验收。

### 6. 保存、索引、下载及云响应失败恢复

步骤：分别注入保存失败、网页取消、索引推理失败/关闭、下载取消/坏文件、云坏格式/超时 → 保留原文/候选 → 本机核对或原操作重试 → 禁止自动重发与部分入库。

证据：`save-coordinator.test.ts` 与关闭保护；`book-extraction-ai.spec.cjs` 真实界面拒绝伪造摘录整批，保留手工内容并取消停滞云请求；`retrieval-cache.test.ts`、`retrieval-engine.test.ts` 检查失败保留旧代、重启接续、晚结果 CAS 与空作品清理；模型下载/安装测试覆盖停滞 DNS/流取消、错误 SHA/长度、空间不足及不替换原模型。

观察的错误是主动注入的技术故障，没有真人误操作率、理解程度或求助次数。这些数值未记录，不能填造。故障分别有专项证据，统一客户端体验以最终桌面及正式包结果为准。

### 7. 归档往返、恢复和导出

步骤：离线建立知识、剧情、伏笔及正文书签 → 快照 → 修改稿 → 导出历史快照核对原稿 → 恢复成新版本 → `.rainsoul` 备份 → 导入新作品 → 重启 → DOCX/TXT 核对正文/引用/伏笔关系。

证据：`tests/desktop/p0-workflow.spec.cjs` 两条完整离线流程读取真实文件并检查 DOCX 内正文 XML，不只看成功提示；恢复不丢当前状态与历史，归档导入为新作品。[快照截图](../learning/项目全流程开发学习/images/snapshots.png)、[知识截图](../learning/项目全流程开发学习/images/knowledge.png)、[伏笔截图](../learning/项目全流程开发学习/images/foreshadow.png)。`source-archive.test.ts`、`source-migration.test.ts`、`knowledge-source-copy.test.ts` 覆盖新增来源/学习注释、升级前快照及复制。模型和缓存不进作品归档，恢复按当前知识 hash 重建。

边界：生产模型资格尚未完成；归档/恢复/导出和索引协议分别可验，不合称正式语义闭环全部完成。

## 实际计时

七条任务没有人工秒数。以下均为系统实测，不是作者完成任务用时。

| 场景 | 实测 | 样本与限制 |
| --- | --- | --- |
| Electron 输入至搜索结果完成渲染 | P95 386.50ms；专项约 3.2 分钟 | 20 种查询各 10 次，共 200 样本，另计 20 次预热；隔离百万字/千条知识；i5-4460 四核、约 8GiB、Windows 10 |
| CPU 模型初始化 | 3780.56ms | 研究 Worker，可能有文件缓存，不是正式 EXE 冷安装 |
| 1000 条首次索引 | 156534.49ms | 短合成知识均单分块，不证明长知识性能 |
| 200 次混合检索 | P95 284.06ms | 30 种固定查询循环，不是 200 种独立文本 |
| 索引同时 30 次保存 | P95 595.78ms；最大 2079.49ms | 实际数据库 Worker，每次约 18000 字，重开确认末次保存 |

首项于 2026-10-10 实测，JSON/截图由 `search-performance.spec.cjs` 写入 `test-results-desktop`，全套测试可能清理并重生成该目录；其余隔离研究原始报告、夹具 hash、CPU/RSS与限制见[模型资格记录](retrieval-model-qualification.md)，临时权重不提交项目。

## 最终核对与待验

- 1.3.0源码最终1119项单元组件、26项开发入口桌面、74项Demo通过；覆盖率四维≥80%。同轮开发入口200样本搜索P95=212.50ms。实际包结果见[执行记录](url-local-retrieval-ledger.md)，不引用修复前失败日志充作成功。
- 已生成1.3.0安装器，49个构建文件逐一hash匹配，实际EXE的CPU运行库输出[2,512]、跨批差0、JS网络入口尝试0；这不等于正式语义门禁已放行。
- 真实公开古文页面获取实际返回“网页获取超时，请手动重试。”；未产生预览与知识，不计为真实网页成功。受控安全及离线粘贴工作台回归已通过，网络可达性和不同网站提取效果仍待验。
- 真实网页效果、正式包离线语义、独立真人标注、模型分发溯源及系统级网络审计逐项核对。
- 真实云与干净 Windows 安装升级卸载保持独立验收，缺环境或凭据时如实待验。
- 首次使用体验需另安排人员执行七条任务，记录真实步骤、用时、求助、误操作、错误恢复。本轮技术回归没有这类观察数据。
