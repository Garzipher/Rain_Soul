# 默认开发学习作品与 Demo 同源 Logo

日期：2026-10-08。范围：本轮从 `125fda9` 基础继续开发；不代表完整 P0 已交付。

## 需求落实

此前仅将学习卡记入任务记录，并把应用内学习作品延后，未落实用户要求。本轮将完整教学源保存在 `learning/项目全流程开发学习/`，按 8 卷 24 章组织，默认作为一个普通作品出现在唯一“作品集”。内容覆盖需求与 Demo、技术选择、架构数据流、编辑、保存、SQLite、质量与 Windows 交付，并明确区分已实现和后续计划。

每章提供原因、步骤、源码联系、示例、证据与练习；`tasks` 只记录交付证据，不能替代学习正文。后续每批开发继续新增课程章，重要勘误单独补章，避免覆盖作者笔记。该要求已补入项目 AGENTS、立项 V2.0、PRD 和技术方案。

## 实现与测试先行

- 构建器读取课程清单和 Markdown，生成包内受限文档。稳定 key 决定卷章身份，真实路径校验拒绝越界和链接逃逸；源正文不会作为 HTML 执行。先观察 5 条有效失败，再实现并扩展至 8 条测试。
- 数据库初始化先校验整份课程，再在临时目录事务创建、关闭后原子发布。已存在的课程仅在事务中追加新卷章；作者改名、正文、顺序、归属和软删除状态保留。原 18 条先观察 15 条失败，再实现；最终 29 条真实 SQLite 测试通过。
- Worker 在作品目录扫描前初始化课程。真实链路测试先观察空书架断言失败，再接线；不向渲染器开放任意文件或初始化命令，不增加联网和 Python 启动依赖。
- 同名用户作品不被接管；固定身份无课程标记、跟踪损坏或 ID 冲突时保留原数据并拒绝写入。异常追加通过 SQLite 触发器验证整笔回滚。已删作品不重启复活，已删卷暂缓补章，恢复后再追加。
- Logo 核对 Demo：27px 天蓝描边圆角方框、浅蓝底、负 9 度旋转和 6px 中心点。SVG 离线生成 PNG/多尺寸 ICO，窗口和 Windows EXE 接入本地素材；侧栏原本已一致。

## 独立审查与复盘

按 gstack review 核对编译路径、身份、SQL、事务、异步错误传播、离线资源和测试兼容。补查发现 SQLite 打开时会自行访问 `-wal/-shm/-journal`，只校验主文件不足；已在打开库前拒绝附属路径链接和非文件，3 条回归先失败后通过。所有已有祖先检查使用 lstat，避免 dangling link 被 existsSync 跳过。最终审查无剩余问题。

可复用结论：应用内教学作品属于作者可编辑的数据，升级不能按同名重建或覆盖正文；使用固定课程身份和单独导入记录，只追加新 key。项目源修订与已安装作者笔记必须有明确边界。
