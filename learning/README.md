# 项目全流程开发学习

这是一部默认出现在 RainSoul 唯一作品集中的普通作品。项目中保存课程 Markdown 真源，客户端按分卷、章节离线阅读和编辑。

目前共 8 卷 24 章：需求与原型、技术路线与工程、桌面进程与安全、正文编辑模型、自动保存与失败保护、SQLite 与卷章管理、质量与 Windows 交付、持续学习与后续 P0。

卷章顺序、标题与文件位置见 [course.json](项目全流程开发学习/course.json)。正文包含背景、技术取舍、步骤、源码联系、例子、验证与练习；未实现的功能明确标为计划。历史测试数属于对应批次，最新验收结果以项目任务记录为准。

维护时先更新对应 Markdown，再检查清单。发布过的 key 不得改用其他章节；后续开发追加新章，既有教学需要纠正时添加勘误或补充章，避免覆盖作者在应用里的笔记。修改仓库源文件后须重新构建，运行中的课程不会自动读取仓库。

`scripts/build-learning-course.mjs` 在构建期生成包内课程，数据库 Worker 启动时幂等初始化普通作品。已导入章不会被正文修订覆盖；新卷章自动补入，作者删除的卷章和作品不自动恢复。同名用户作品互不影响。

剧情架构、伏笔架构与知识库完成后，将把模块大纲、接口与数据流联系、学习卡关联到此作品；当前先以正文组织，不虚称这些能力已经交付。
