# 项目全流程开发学习

这是一部默认出现在 RainSoul 唯一作品集中的普通作品。唯一教学真源是 `learning/项目全流程开发学习/`，构建后随客户端离线提供。当前共 **8卷37章、17张离线图片**；卷章稳定 key 与 Markdown 文件位置见 [course.json](项目全流程开发学习/course.json)。

## 怎样读这本实践教材

每章先解释本章使用的技术、术语和原理，再沿真实源码剖析项目中的应用，最后给出跟做步骤、预期结果、故障排查、拓展练习与参考答案。它不是提交日志合集，也不要求读者预先精通所有框架。

| 学习阶段 | 阅读顺序 | 要完成的产物 |
| --- | --- | --- |
| 需求入门 | 第一卷01→02→03 | 一张可验证需求卡和一次关闭重开证据 |
| 编程与工程 | 第二卷01→02→03 | React/TS/运行环境分工与保存调用地图 |
| 桌面边界 | 第三卷01→02→03 | 窗口权限、IPC校验、Worker回执解释 |
| 正文模型 | 第四卷01→02→03 | 合法文档树、稳定ID和Unicode计数实验 |
| 可靠保存 | 第五卷01→02→03 | 防抖、迟到回执、幂等与关闭时间线 |
| 数据关系 | 第六卷01→02→03 | SQLite/WAL、迁移、卷章和软删除恢复实验 |
| 质量交付 | 第七卷01→02→03 | Red/Green证据、独立提交与目录包/卸载边界 |
| 完整主流程与P1首批 | 第八卷01→16 | 图文教材编译、知识/剧情/伏笔、快照、手稿、归档、AI、性能、需求会话及本地拆书实验 |

不熟悉 Promise、SQL、JSON、UTF-8、CSS Grid 或 token 时，先读对应章的“技术基础”，再跟读源码。每章教学示例注明简化边界，不能用简化代码直接替换生产实现。根目录统一使用 PowerShell，依赖按 package-lock.json 安装；不要在真实稿件上故意制造失败。

图文阅读展示标题目录、代码高亮、表格和实际系统截图；Markdown 源文只读，用于核对原始语法。旧版“正文—作者笔记”入口已经取消，已有数据库正文保留，不因删除入口而清空。普通小说和作者自建普通章继续用固定样式编辑器；当前图文教材不意味着所有作品已支持 Markdown 编写或插图。

## 本书的真实状态

本地 P0 主流程与云端兼容适配已经实现，正文、知识关系、快照、归档、文件往返和部分云端边界都有自动化证据。AI 测试使用受控响应，不代表真实供应商已联调或文学质量达标。干净 Windows 安装/升级/卸载、实际 Microsoft Word 打开、真实云端兼容/计费仍应分别验收。各章历史测试数与性能成绩只属于其记录批次，最新结论以本轮真实输出为准。

P1首批需求会话与本地TXT/DOCX逐段拆书已进入实际客户端及桌面用例验证；会话云授权仍未发真实请求。自动AI拆文/URL、跨作品 AI 分析、XMind、本地模型与向量检索仍是后置能力。知识库储备参考描写并辅助作者学习和 AI 选用，逐段摘选与审核入库不等于把整本手稿导入新作品。

## 维护与构建原则

先修 Markdown 真源，再核对清单和图片。每章必须说明概念、具体源码函数/路径、接口/进程/数据流、跟做结果与排错，而不是复制一段通用模板。截图应由真实客户端生成，批准路径使用 `images/名称.png`，不能引用维护者电脑绝对路径或远程图片。

`build-learning-course.mjs` 把课程编译为默认普通作品初始化数据；`build-textbook.mjs` 保留 Markdown 并校验本地 PNG，Vite 教材插件把读本与内容 hash 图片加入客户端。代码高亮不执行示例，教材图片不写入受限小说正文。

稳定 key 不得挪给另一章。包内只读讲解可以继续修订；已安装作品只增量追加未跟踪的新卷章，保留作者编辑、顺序、归属和删除状态。需要提醒旧正文读者的重大更正，应写明确勘误，不能静默覆盖 document_json。修改显示标题不改变对象身份，同名自建作品不被默认课程接管。

维护者验证先检查课程与读本构建，再运行相关 builder/seed 测试；完整产品门禁由主开发流程统一执行，避免测试期间并行重建 dist 或覆盖正在运行的 EXE。
