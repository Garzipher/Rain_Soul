# 统一控件与错误状态设计

## 本章目标

理解设计变量、无障碍控件、模态弹层和异步错误分类如何共同影响桌面应用的可用性。读完后能解释：为什么按钮看起来一致却仍可能无法使用，为什么“保护数据”也可能错误地锁死整个窗口。

## 一、设计变量的原理

CSS 自定义属性把重复使用的视觉决定保存成命名值。颜色、控件高度、圆角和投影由应用统一定义；页面只负责布局。它和 TypeScript 的常量有相似目的：让相同概念只有一个定义，修改时不需要逐页猜测。

```css
:root {
  --line: #d9dfe6;
  --surface: #fff;
  --surface-muted: #f5f6f8;
  --control-height: 34px;
  --radius-control: 8px;
}
```

在 RainSoul 中，`src/renderer/styles.css` 定义这些变量。浅灰工作底与白色表面区分工作区域；较深边界让控件可辨认，小投影提示卡片层次。正文编辑区仍是无框白色页面，因为作者的注意力应落在文字上。

基础控件使用 `:where(...)`，它的选择器优先级为零。页面可以通过明确类名修改特殊控件，例如两行知识摘要按钮无需常规按钮的内边距。若基础规则直接使用强优先级或不断追加 `!important`，局部组件会越来越难维护。

## 二、下拉菜单为什么需要组件

原生 select 提供选择值和键盘行为，但展开列表的外观由系统控制。只修改闭合输入框，无法让不同页面的展开菜单一致。自定义菜单则必须重新处理焦点、键盘、禁用项和滚动；遗漏这些能力会制造看起来漂亮但不能使用的控件。

本项目选择 Radix Select 提供交互基础，`SelectField` 负责受限业务接口和外观。它接受已有 option 声明，选择后通知真实字符串值：

```tsx
<SelectField value={mode} onChange={event => setMode(event.target.value)}>
  <option value="keyword">关键词</option>
  <option value="semantic">语义</option>
</SelectField>
```

组件内部把值编码为 `choice:原值`，因为 Radix 对空字符串有占位语义，而项目中的“未关联”可能就是一个合法空值。通知业务时会解码；表单隐藏字段仍保存原值，不能把组件编码当作数据库枚举。

## 三、模态窗口与弹层

Electron 中的网页也遵守浏览器的布局规则。`dialog.showModal()` 会把窗口放入浏览器顶层，并让外部内容不可交互。普通 portal 到 body 的菜单即使 z-index 很高，也可能无法覆盖这个顶层窗口。

因此 `SelectField` 打开菜单前查找触发按钮最近的 dialog，把菜单放到同一个模态窗口内。按 Esc 时先关闭菜单，不能同时关闭整个编辑表单。父表单的焦点循环也必须排除隐藏的表单字段，否则 Tab 可能跳入看不见的控件。

相关源码：`src/renderer/components/select-field.tsx`、`select-field.css`、`workspace-tool-dialog.tsx`。

## 四、错误分类比错误文字更重要

会话发送包含读取设置、检查版本、读取凭据、请求云服务、保存回答和返回回执几个步骤。每步异常的含义不同：

| 已知事实 | 页面下一步 |
| --- | --- |
| 明确失败，没有待保存完整回答 | 保留草稿，可修改设置或手动重试 |
| 完整回答已收到但保存未确认 | 查看回答，使用原请求保存或明确放弃 |
| 没有收到 IPC 回执 | 只核对本机记录，不能自动发第二次云请求 |

旧实现把三个事实都设置为 `pendingReply`，再通过全局未保存状态阻止导航和关闭。读取凭据失败就造成了死锁。修正入口是 `ConversationAiCommands.execute`：明确失败返回 `CONVERSATION_SEND_FAILED`，待保存和进行中的错误码保留。前端按码决定恢复路径，而不是匹配一段厂商错误文字。

`ConversationReplyRecovery` 在出现未知回执后自动读取本机记录。它没有调用云服务的权限；没有待存回答时重新读取会话并解除状态，有回答时继续给作者保存和查看操作。这是减少误锁同时保留数据保护的做法。

## 五、固定分页与滚动容器

知识库的内容区使用纵向 flex：工具栏、标签、结果、分页。只有结果区设置 `overflow: auto`，分页是不会收缩的同级元素。父级都设置 `min-height: 0`，让结果区能缩到剩余高度。

如果把分页放进结果滚动区，翻到列表底部才会看到它；如果父级保持默认最小内容高度，结果会撑大容器，分页也会被推到窗口之外。源码在 `knowledge-workspace.tsx/css`。
