# 草稿回执与跨作品证据

本章学习两个问题：作者审核到一半关闭程序，怎样继续；入库已经成功但界面没收到回执，怎样避免重复创建知识。先阅读第五卷的幂等重试与第六卷的SQLite事务。这里的“恢复”主要读取本机草稿，不表示重新调用付费模型。

第八卷第17章记录了当时仅有主进程缓存的实现。本轮升级为持久草稿，原著摘录与学习讲解也分表保存；本章说明升级后的行为，旧章作为阶段学习记录保留。

## 1. 原理：状态、事务与比较后写入

UI状态在进程结束后消失。持久草稿保存冻结来源、完成的AI批次、人工审核和待核对请求；一次性云授权不保存。文件使用临时文件写入、sync、rename，写失败保留旧草稿。JSON严格协议先检查字段、容量和原文哈希，损坏不能静默当作空任务。

数据库事务只能保护同一数据库的写入，不能把网络回答和JSON文件一起回滚。设计因此区分两种回执：云结果ready是已收到可核对文本；知识入库committed是作品事务和操作回执已经提交。未知入库结果保存原operationId、requestHash与expectedRevision，先查询本机回执，缺失才重放原请求，不能刷新版本后构造第二次入库。

比较后写入（CAS）要求当前任务ID仍与调用方读到的任务ID一致。仅先读再写存在间隙：另一个操作可能替换素材。协调器按作品串行，草稿文件再检查expectedTaskId；清空pending请求还校验operationId和hash。串行控制顺序，CAS控制身份，两者解决不同问题。

## 2. 项目实现：只暴露受限操作

```text
shared/extraction-draft.ts：来源、批次、审核、pending严格schema
main/extraction-draft-store.ts：原子文件保存、hash核验、CAS
main/extraction-draft-coordinator.ts：begin/saveReviews/recordBatch/commit/recover
main/book-extraction-ai-commands.ts：发前保存running，完成保存ready
workers/database/book-extraction.ts：作品事务、快照及入库回执
workers/database/source-copy.ts：跨作品证据身份映射
```

recordBatch只能追加或完成当前来源的同一批次，不能改来源、已完成回答或审核状态。网络发送前持久running，失败或取消保留以前的ready；重启把未完成批次标为cancelled，禁止自动联网。rawText与结构化suggestions分别保存：JSON或逐字摘录核验失败时，完整回答仍可看，整批不可应用。

已完成拆书建议绑定冻结原文和分类标签。另一批入库只改变作品revision，不应迫使已付费候选重新联网；发送前的revision核验仍严格。原文替换、分类标签改名或删除仍阻止采纳。这与修改正文的AI候选不同：正文候选还绑定生成时的正文，不能跨稿直接应用。

## 3. 跨作品复制为什么需要新ID

作品分别拥有SQLite库。复制知识不能只复制body与origin_json，否则网页原文与学习注释会消失；也不能引用源库的段落ID，否则源作品删除或恢复会影响目标追溯。实现先在来源只读事务读取版本、知识和关联证据，再在目标事务写知识、全新来源及段落ID、映射后的关联和全新注释ID。原文、哈希、网址和获取时间保持冻结值。

```typescript
// source-copy.ts逻辑节选：内容复制，关系映射，身份独立。
const segmentIds = new Map(original.segments.map(segment => [segment.id, randomUUID()]));
const source = { ...original, id: randomUUID(),
  segments: original.segments.map(segment => ({ ...segment, id: segmentIds.get(segment.id)! })) };
```

同一目标事务中任何注释插入失败，都回滚知识、来源、版本和回执。幂等重放返回已提交结果，不再读取后来已删除的来源。目标分类与标签由作者选定，来源分类ID不会直接穿透两个库。

## 4. 跟做：恢复审核而不重新收费

1. 在拆书工具粘贴合成素材，编辑一段学习笔记，等待草稿保存。
2. 正常关闭并重启，打开同作品与拆书工具，检查来源、审核文本和分页材料仍在。
3. 没有云配置也能完成手工审核；有云配置时逐次确认后生成建议，重启核对已有ready应不新增请求。
4. 入库后在全局知识页查看该条，复制到另一作品。删除原作品里的知识后，目标证据仍独立存在。
