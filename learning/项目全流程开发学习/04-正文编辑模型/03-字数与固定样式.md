## 1. 字数并不等于字符串长度

“雨A1， B2”中，有汉字、字母、数字、空格和标点。
字符串长度会把大部分字符全部算入，某些字符还受UTF-16编码影响。
用户确认的统计口径排除标点、空白与换行。
所以不能直接把 `text.length` 当正文写作字数。

当前实现按 `for...of` 遍历Unicode码点。
汉字使用Unicode脚本属性判断，字母数字当前使用ASCII范围。
它能处理补充平面汉字“𠮷”，但不把全角数字“１２”当ASCII数字。
这类边界必须公开说明并有测试，而不是口头说“所有数字”。

## 3. 直接运行字符边界实验

下面完整Node程序可以通过PowerShell执行，不写数据库。
它与计数条件一致，用于观察字符是否被纳入。
先创建变量，再通过管道把JavaScript传给Node。

```powershell
$counter = @"
const sample = '雨A1， B2\n𠮷！１２é';
let count = 0;
for (const character of sample) {
  const counted = /[\p{Script=Han}A-Za-z0-9]/u.test(character);
  if (counted) count++;
  console.log(JSON.stringify(character), counted ? '计入' : '不计入');
}
console.log('总字数：', count);
"@
$counter | node
```

预期总字数6：雨、A、1、B、2、𠮷。
逗号、空格、换行、感叹号、全角数字与é不计入。
这只是算法观察，生产函数还需要遍历合法文档节点。
下一步运行项目实际测试，避免示例与实现脱节。

```powershell
npm run test:unit -- tests/unit/document.test.ts
```

找到同样的样本与期望6。
以后扩展规则，这个测试会提醒你旧行为发生改变。
先修改需求与边界测试，再实现新规则，不能只改正则后宣称完成。

## 5. 样式应由规则统一

正文内容存文本，字体和间距由样式系统决定。
这让作者专注写作，不因每次粘贴带入不同排版。
用户已明确首版固定一套样式，自定义样式后续再评估。

```powershell
Select-String -Path .\src\renderer\styles.css `
  -Pattern 'chapter-title|writing-body' -Context 0,2
```

当前章标题使用微软雅黑、16pt、粗体。
正文使用微软雅黑、12pt、1.5倍行高、固定正文色。
正文段落间距由 `.writing-body p` 定义。
作品名作为工作区标题，不应在正文机械复制一遍造成重复。

DOCX最终也要使用明确映射，但导出未完成前不能假定其排版已验收。
屏幕样式与导出规则需要共同测试。
TXT则保留内容顺序，不携带字体等视觉设置。

## 6. 没有蓝框，不等于没有可访问性

正文去掉焦点外框，是用户明确的写作体验要求。
按钮、输入等其他控件仍有可见键盘焦点样式。
标题输入以轻微下划线提示焦点，正文以光标和编辑状态反馈。

```powershell
Select-String -Path .\src\renderer\styles.css `
  -Pattern 'focus-visible|writing-body:focus' -Context 0,1
Select-String -Path .\src\renderer\components\chapter-editor.tsx `
  -Pattern 'aria-label|aria-multiline' -Context 0,1
```

编辑器具有“章节正文”名称与多行语义。
取消视觉边框，不能顺手删可访问名称或禁用键盘操作。
测试应检查真实聚焦与输入，而不是只查CSS包含outline:0。

## 7. 展示字数与落盘字数的区别

界面从当前草稿计算实时字数，所以能在保存前立即变化。
仓储保存时也从文档计算字数，用于持久化摘要。
服务端不能直接相信页面传来的数字。

若保存失败，实时数字仍反映窗口草稿，书架摘要可能尚未更新。
这并不意味着草稿已保存。
作者应先解决保存失败，再切换或关闭。
第五卷会把实时草稿与已保存版本的区别讲完整。

## 常见问题与排查

| 现象 | 检查 | 处理 |
| --- | --- | --- |
| 标点增加字数 | 是否错误使用length | 对照真实计数函数 |
| 全角数字没计入 | 当前ASCII边界 | 按确认后的规则扩展测试 |
| 标题输入数字不变化 | 标题不在正文document | 在正文观察增量 |
| 字数变了卡片没变 | 草稿与持久化状态 | 等待成功保存并刷新 |
| 去蓝框后按钮也没焦点 | CSS范围是否过宽 | 保留其他控件焦点反馈 |
