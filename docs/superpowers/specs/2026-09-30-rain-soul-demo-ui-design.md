# Rain_Soul Demo 工作台界面设计

## 目标

将现有视觉 Demo 调整为可供后续开发参考的 Codex 风格写作工作台，覆盖作品集、写作页、知识库、需求会话和设置五类入口，并演示作品树的右键删除交互。

## 视觉方向

- 采用深石墨侧栏、浅灰工作区、白色内容面板和单一蓝绿色强调色。
- 使用细边框、克制阴影和统一间距，避免渐变和装饰性大色块。
- 头像下直接显示 `山间雨`，不显示“笔名”标签。
- 产品可见文案统一使用“作品集”，不再使用“我的作品”。

## 导航与布局

- 侧栏默认收起，展开/收起按钮使用方形菜单按钮并提供无障碍名称。
- 展开时显示 RainSoul、头像、作品集、知识库、需求会话；设置固定在侧栏底部。
- 收起时保留图标和工具提示，移动端保持入口可达。
- 作品集页面不显示“已保存”；保存状态只在写作页显示。

## 交互参考

- 作品卡、卷、章节支持右键打开上下文菜单。
- 删除动作先显示确认对话框；确认后只从当前 Demo 状态移除，作品树和计数同步更新。
- 删除卷的提示说明会连同其章节一起移除。
- 保存失败状态继续阻止切换、删除和离开写作页。
- 知识库提供搜索、分类、标签筛选、条目列表和详情参考界面。
- 需求会话提供会话列表、消息流和授权提示参考界面。
- 设置提供头像/显示名称、编辑器固定样式、数据目录、备份和云端 AI 授权参考控件。

## 非目标

- Demo 不连接 SQLite、不写磁盘，也不实现真实 AI、知识库或需求会话后端。
- 右键删除只演示交互和状态变化，不代表最终数据删除协议。

## 验收

- 桌面和窄屏视口均无横向溢出。
- 所有入口可切换，未出现空白占位页或错误控制台。
- 新建作品、编辑正文、保存失败态、右键菜单和删除确认可操作。
- 作品集首屏不出现“已保存”或“我的作品”。
