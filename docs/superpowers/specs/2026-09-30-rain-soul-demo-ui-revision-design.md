# RainSoul Demo 工作台界面修订设计

## 目标

在现有单文件视觉 Demo 上完成一轮界面和交互基线修订，为后续 Electron + React/TypeScript 实现提供可直接参考的工作台原型。Demo 只在浏览器内存中演示状态，不连接 SQLite、不写磁盘、不调用真实 AI 服务。

## 已确认范围

- 采用单文件 Demo 增量重构方案，继续使用 `docs/demos/rainsoul-writing-style.html`。
- 工作台整体采用白色 Codex 风格，主色为天蓝色，保留细边框、克制阴影和小圆角。
- 恢复第一版 RainSoul 标题和 Logo：倾斜方框加右上角圆点，旁边显示 `RainSoul`。
- 侧栏默认收起，收起后保留方框菜单按钮；展开后显示头像、笔名值、作品集、知识库、需求会话和设置。
- 作品集使用“作品集”文案，不出现“继续创作”“所有作品都在这里，最近编辑的排在前面”“最近编辑优先”或“已保存”。
- 写作页右上角不显示新建作品按钮；新建作品入口保留在作品集页。
- 设置页改为纵向单列分组：个人资料、编辑器、本机数据、知识库维护、云端 AI。

## 页面设计

### 作品集

作品集首屏直接展示作品卡片和作品数量。作品卡保留作品名、类型、摘要、章节数和字数等信息。卡片支持左键进入写作页，右键打开删除菜单。保存状态仅在写作页显示。

### 写作页

保留作品结构树、编辑器、实时字数和保存失败保护。作品树中的作品、卷和章均有稳定的可定位节点，支持右键删除。写作页右上角不显示新建作品按钮。

### 知识库

- 顶部提供紧凑的模糊搜索框，搜索正文内容、出处和标签；移除独立的“搜索条目”搜索框。
- 分类示例改为“全部、人物描写、景物描写、内心描写、经典引用”等。
- 标签一览末尾提供“添加标签”入口。标签筛选继续表达多个标签同时满足的 AND 规则。
- 移除右侧“条目详情”面板和标题。
- 卡片不显示单独条目标题，只显示最多两行正文摘要和右下角出处。
- 点击卡片后，在原卡片下方展开全文、分类和标签；再次点击收起。展开状态保存在浏览器内存。
- 知识库页面提供“新增知识”入口；“新添知识库”不在此页面出现。
- 顶部提供“拆书工具”入口，点击进入独立拆书参考工作区。

### 拆书参考工作区

拆书工具以 Demo 形式展示 TXT/DOCX 导入闭环：选择文件、识别常见章节标题、预览章节、提示图片和表格等不导入内容、确认后创建新作品。当前只展示步骤和状态，不读取真实文件。

### 需求会话

- 侧栏保留“需求会话”入口，内容区不再显示该大标题，也不显示新建作品按钮。
- 页面顶部显示当前作品名，左侧显示该作品下的会话列表，右侧显示类似 Codex 的消息流和输入区。
- 删除“当前上下文”面板和“记录一个想法或问题”占位文案，输入区保留简洁输入提示和发送按钮。
- 每个会话项右侧增加删除按钮，默认隐藏，仅在鼠标悬停会话项时显示；删除前显示确认弹窗。

### 设置

设置采用上下排序的纵向分组，保持单列阅读顺序。除已有的个人资料、编辑器、本机数据、云端 AI 外，增加“知识库维护”分组，演示分类和标签维护入口。分类删除仍提示先迁移条目。

## 状态与交互

### 导航和侧栏

统一使用 `show(view)` 管理页面切换、顶部标题和导航选中态。侧栏收起状态由根节点 class 表达，菜单按钮带有 `aria-label`、`title` 和 `aria-expanded`。窄屏下仍保证菜单按钮和导航入口可触达。

### 删除确认

右键菜单只保留与当前节点相关的删除命令。打开确认弹窗前，将待删除对象复制到独立的 `pendingDelete` 状态；关闭右键菜单不会清空该状态。确认标题必须准确为：

- 作品：`删除作品`
- 卷：`删除卷及章节`
- 章节：`删除章节`

确认后只更新 Demo 内存中的 DOM 和计数，不代表最终数据删除协议。保存失败状态下禁止删除并提示先恢复保存。

### 知识卡片

卡片使用事件委托处理点击和动态筛选。搜索、分类、标签筛选共同决定可见性；点击卡片只切换当前卡片的展开状态，不跳转页面。

### 会话

会话列表使用事件委托处理选择和删除。删除按钮默认透明并不可见，悬停会话项时显示；删除当前会话后自动选中剩余会话，全部删除时显示空状态。

## 视觉规范

- 页面背景以白色和浅灰为主，侧栏使用白色，边界通过 `#e2e8f0` 级别的细线表达。
- 天蓝色用于主按钮、选中态、焦点态和链接，正文使用深灰，错误使用红色，成功状态仅在写作页显示。
- 卡片和面板圆角控制在 4 到 8px，阴影只用于浮层、弹窗和悬停反馈。
- 使用现有 Lucide 图标，所有图标按钮提供可访问名称和工具提示。

## 验收

- 作品集没有“继续创作”“所有作品都在这里，最近编辑的排在前面”“最近编辑优先”和“已保存”。
- 写作页没有右上角新建作品按钮。
- 侧栏默认收起，展开和收起均可用，收起时显示方框菜单按钮。
- 知识库可模糊搜索，分类包含描写类和经典引用类，卡片最多两行摘要，点击后原位展开全文，右下角显示出处。
- 知识库顶部可进入拆书参考工作区，设置页包含知识库维护分组。
- 需求会话符合“作品 → 会话列表 → 对话区”结构，没有当前上下文框和旧占位文案，会话删除按钮只在悬停时显示。
- 作品、卷、章节右键删除后确认弹窗标题准确，删除目标不会因关闭右键菜单而丢失。
- 保存失败保护继续阻止切换和删除，恢复保存后可继续操作。
- 桌面和窄屏视口无横向溢出；页面切换、搜索、卡片展开、会话删除和弹窗交互无控制台错误。

## 非目标

- 不实现真实 Electron 主进程、SQLite、文件导入、AI 调用或云端授权。
- 不在本轮开放编辑器自定义样式。
- 不加入 EPUB/PDF、URL 导入、XMind、向量检索等后置功能。
