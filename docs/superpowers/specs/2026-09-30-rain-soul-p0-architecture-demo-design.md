# RainSoul P0 剧情与伏笔架构 Demo 设计

## 目标与依据

补齐现有 Demo 遗漏的 P0 作品架构入口，让作者能从同一部作品中查看正文、规划剧情，并追踪伏笔与正文证据。V2.0 将剧情架构称为“大纲”，两者指同一能力；作品详情包含大纲和伏笔架构，分别按卷、章、详细节点和五状态证据组织。参见 `docs/Rain_Soul_项目立项方案_V2.0.md` 第 5.2、6.3、6.4 节。早期原型梳理中“伏笔后置”的说法已由 V2.0 的 P0 决策覆盖。

本轮只扩充 `docs/demos/rainsoul-writing-style.html` 中的交互示意。所有变更保存在浏览器内存，刷新后重置；不模拟 SQLite 持久化，也不把演示交互描述为已交付的正式功能。

## 页面与导航

- 进入一部作品后，在作品工作区顶部提供 `正文`、`剧情架构`、`伏笔架构` 三个标签页。标签页属于当前作品，不放入全局侧栏；切换标签不改变当前作品。
- `正文` 保持现有卷章树、编辑器、字数和保存状态。切换到另外两个标签前沿用现有保存保护；保存失败时停留在正文并提示原因。
- `剧情架构` 展示可展开的卷 → 章 → 详细节点树。没有卷时允许作品直接拥有章级节点；节点可关联同作品的现有章节、知识条目及伏笔。大纲节点与正文章节是不同对象，关联不会自动创建或覆盖章节。
- `伏笔架构` 展示当前作品的伏笔列表和所选伏笔详情，包括状态、所属剧情节点，以及埋设、触发、回收的章节与段落证据。没有数据时显示创建入口和清楚的空状态。
- 标签、空状态和操作在桌面及窄屏均可读；切换作品后显示该作品自己的架构数据，不混用上一部作品的选中节点。

## 剧情架构交互

作者可以新增、重命名和删除卷、章、详细节点，调整同级顺序，并将节点关联到已有章节。节点详情提供关联现有知识和伏笔的入口，允许多选知识条目；关联范围限制在当前作品。选择关联项后可跳转到对应章节、知识卡片或伏笔详情。删除节点前确认；与该节点关联的伏笔保留，但解除已失效的大纲关联。树操作不能形成父子环。

Demo 展示大纲结构、关联和跳转的交互结果。大纲编辑复用现有 Demo 的保存状态规则；正式产品仍须按 V2.0 实现自动保存、版本与快照。大纲节点不自动生成正文章节，XMind 导入不在本轮实现。

## 伏笔架构与正文书签

伏笔有 `未埋设`、`已埋设`、`已触发`、`已回收`、`废弃` 五种状态。作者可以创建伏笔、修改名称和状态，并给埋设、触发、回收分别添加当前作品的章节和段落证据。一个阶段允许多个证据；证据显示章节名称、段落摘录和可点击的定位入口。状态修改不暗中生成证据；缺少证据时明确显示“尚无证据”。

正文可插入可点击的伏笔行内标记。插入前选择当前作品已有伏笔，默认关联光标所在段落；多段选区取首段。点击标记打开该伏笔详情，可从详情返回对应正文段落。标记不计入字数；删除标记只解除当前位置的关联，不删除伏笔。Demo 的作品与章节使用演示期唯一且不复用的键，段落和伏笔使用独立 ID；正式产品统一使用数据库稳定 ID，不用标题或字符偏移做持久关联。手工证据可选正文段落并精确定位；仅填写摘录时定位到章节。段落或章节被删除后，失效证据不得继续跳转到错误位置；界面保留原来源，允许作者清理或重新关联。

## 演示状态与清理

- 每部作品拥有独立的剧情节点、伏笔、证据和正文标记。示例作品可预置少量关联数据，帮助查看从节点到正文、从正文到伏笔的路径；新作品从空架构开始。
- 删除作品时，按既有确认流程同步清理这部作品的剧情节点、伏笔、证据和标记；切换到剩余作品后不得显示已删作品的数据。
- 删除卷或章节时，清除或标记其失效的架构关联、章节与段落证据和正文标记，不得把原关联误指向别的章节。保留的伏笔仍可编辑。
- Demo 的内存态只用于验证界面关系；正式版的稳定 ID、软删除、自动保存、快照和恢复仍以 V2.0 为准。

## 验收

1. 进入任一作品可看到并切换 `正文`、`剧情架构`、`伏笔架构`；全局侧栏结构不变，保存失败时不能离开正文。
2. 剧情树可按卷 → 章 → 详细节点浏览和编辑；可关联、查看并定位同作品现有章节、多个知识条目和伏笔，不自动创建正文章节，也不能形成父子环。
3. 伏笔可创建并切换五种状态；埋设、触发、回收证据分别显示章节、段落摘录和定位入口，缺失证据有明确提示。
4. 正文伏笔标记可插入、点击查看详情和反向定位；标记不计字数，移除标记后伏笔仍存在。
5. 切换作品时架构数据隔离；新作品显示空状态；删除作品或章节后不出现已删对象的残留条目、错误跳转或控制台异常。
6. 桌面和窄屏下标签、树、证据与空状态均可操作，键盘能够切换标签和触发主要命令。

## 非目标

- 本轮不实现真实数据库、跨重启保存、完整版本恢复或实际 AI 剧情分析；这份 Demo 只展示入口、状态和关联路径。
- 不实现 XMind 导入、自动生成章节、跨作品知识实时共享、向量检索或自动改稿。
